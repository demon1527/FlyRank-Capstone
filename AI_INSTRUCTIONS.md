# AI Development Instructions

## AI Tool

This project uses ChatGPT as an AI-assisted development tool.

## Project Context

This repository is used for the FlyRank Frontend AI Engineering Internship capstone project.

## Development Guidelines

When using AI assistance:

- Follow the existing project structure and conventions.
- Prefer clear, readable, and maintainable code.
- Explain suggested changes when necessary.
- Do not expose API keys, credentials, or environment variables.
- Use semantic and accessible HTML where applicable.
- Keep frontend code responsive and user-friendly.
- Review AI-generated code before adding it to the project.

## Git Conventions

This project follows Conventional Commits.

Examples:

- `feat: add navigation component`
- `fix: resolve mobile layout issue`
- `docs: update project documentation`
- `refactor: simplify component logic`
- `chore: update project configuration`

## AI Usage

AI may assist with:

- Code review
- Debugging
- Documentation
- Refactoring suggestions
- Development guidance

All AI-generated suggestions should be reviewed and understood before implementation.
